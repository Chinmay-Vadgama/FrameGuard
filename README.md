# FrameGuard — AI-Generated Video Security Scanner

FrameGuard is a personal security-inspection API for **AI-generated video files downloaded from untrusted websites or received from sources you do not trust**. Its job is to inspect the video file before you open, edit, or share it.

It is a video-file scanner, **not** an AI-video detector, website reputation service, or video downloader. It does not determine whether a video was genuinely generated by AI, whether its visuals are authentic, or whether a website is trustworthy. It does not fetch YouTube, social-media, or other URLs. Only upload video files that you are authorized to obtain and scan.

## What it checks

- **VirusTotal (optional, configurable):** checks the SHA-256 against an existing VirusTotal report; if no report exists and automatic upload is enabled, submits the file for multi-engine analysis.
- **FFprobe:** parses the container and reports streams, codecs, dimensions and duration.
- **FFmpeg:** attempts to decode the audio/video streams and reports decoding errors or timeouts.
- **ExifTool:** extracts selected file and media metadata, including software and codec fields where available.
- **SHA-256:** calculates a content fingerprint for identifying the exact file and correlating reports.

A valid-looking video is not necessarily safe. These checks are preliminary inspection, not a guarantee that a file is harmless and not a fully isolated malware sandbox.

## Render Free deployment

The project is designed for a small Render Free web service (512 MB RAM). ClamAV is not installed or run; VirusTotal performs the multi-engine malware analysis remotely when enabled. FFprobe, FFmpeg and ExifTool run locally and sequentially to reduce resource use.

1. Create a GitHub repository and upload the contents of this folder.
2. In Render, select **New + → Blueprint** and connect the repository.
3. Render detects `render.yaml`; deploy the `free` web service.
4. In the Render dashboard, open the service's **Environment** page.
5. Set `VIRUSTOTAL_ENABLED=true` and add `VIRUSTOTAL_API_KEY` as a secret environment variable if you want VirusTotal scanning. Keep the key private.
6. Leave `VIRUSTOTAL_UPLOAD_UNKNOWN=true` to submit files that do not already have a VirusTotal report, or set it to `false` to do hash lookups only.
7. Keep the generated `API_TOKEN` private. Check `https://YOUR-SERVICE.onrender.com/health` after deployment.

Do not commit `.env`, API tokens, or VirusTotal keys to GitHub.

## VirusTotal: privacy, terms and limits — read before enabling

- The default integration uses VirusTotal's **standard/public API**. Files submitted through it are added to the VirusTotal dataset and may be accessible to the security community and partners. VirusTotal also warns that indicators queried through the API may be added to its dataset. Do not submit private, confidential, personal, or sensitive videos—or query sensitive indicators—unless your agreement and sharing expectations explicitly permit it.
- VirusTotal's public API is intended for non-commercial use and is limited to **4 requests per minute and 500 requests per day**. It must not be used in a commercial product or service. If this API is ever offered to other users or used commercially, obtain the appropriate VirusTotal licence first.
- VirusTotal's Private Scanning service has separate licensing and privacy characteristics; importantly, its private analyses do **not** include antivirus-engine verdicts. Do not assume that private scanning is a drop-in replacement for public multi-engine malware verdicts.
- The API checks for an existing report by SHA-256 first. If there is no report and `VIRUSTOTAL_UPLOAD_UNKNOWN=true`, it uploads the video. Files up to 32 MiB use `/files`; larger files use VirusTotal's one-time upload URL endpoint. The service supports your configured 100 MiB maximum, within VirusTotal's documented 650 MB upload ceiling.
- A new upload returns an analysis ID and `malware_analysis_pending`. Poll the returned `analysis_endpoint` with the same `X-API-Key` header to retrieve the eventual result. Poll sparingly to respect your API quota.
- A hash lookup can reveal whether VirusTotal already knows a file, but a previously unseen file is not considered clean. `not_found`, `submitted`, `rate_limited`, and `error` are not clean verdicts.

If you do not want videos sent to VirusTotal, leave `VIRUSTOTAL_ENABLED=false`. Local FFprobe, FFmpeg and ExifTool checks will still run.

Official references:
- [VirusTotal API overview and public API restrictions](https://docs.virustotal.com/docs/api-overview)
- [VirusTotal file upload API](https://docs.virustotal.com/reference/files-scan)
- [VirusTotal large-file upload URL](https://docs.virustotal.com/reference/files-upload-url)

## Supported video formats and size

The default maximum is **100 MiB** (104,857,600 bytes). Supported filename extensions: MP4, M4V, MOV, MKV, AVI, WEBM, MPEG, MPG, 3GP, TS and OGV. An extension does not prove the content is a valid video; FFprobe performs a content-level parse.

## API endpoints

- `GET /health` — service and tool configuration.
- `POST /scan` — upload one video file as multipart field `file`.
- `GET /virustotal/analyses/{analysis_id}` — retrieve a submitted VirusTotal analysis.
- `GET /docs` — interactive API documentation.

All endpoints require `X-API-Key`, except the root health/readiness information (`/` and `/health`).

### Example scan

```bash
export SCANNER_URL="https://YOUR-SERVICE.onrender.com"
export SCANNER_TOKEN="your-render-API_TOKEN"

curl --fail-with-body \
  -H "X-API-Key: $SCANNER_TOKEN" \
  -F "file=@/path/to/ai-generated-video.mp4" \
  "$SCANNER_URL/scan" | python3 -m json.tool
```

If VirusTotal submits a new analysis, the response contains `virustotal.analysis_id` and `virustotal.analysis_endpoint`. Check the result later:

```bash
curl -H "X-API-Key: $SCANNER_TOKEN" \
  "$SCANNER_URL/virustotal/analyses/URL_ENCODED_ANALYSIS_ID" | python3 -m json.tool
```

### Example configuration

```dotenv
API_TOKEN=replace-with-a-long-random-secret
MAX_UPLOAD_MB=100
SCAN_TIMEOUT_SECONDS=120
VIRUSTOTAL_ENABLED=false
VIRUSTOTAL_API_KEY=
VIRUSTOTAL_UPLOAD_UNKNOWN=true
```

Set these in Render's Environment settings. `VIRUSTOTAL_API_KEY` should be stored as a secret. `VIRUSTOTAL_UPLOAD_UNKNOWN` controls whether an unknown hash is uploaded; it does not affect lookups for existing reports.

## Run locally with Docker

```bash
cp .env.example .env
# Edit .env, set API_TOKEN, and optionally configure VirusTotal.
docker build -t frameguard .
docker run --rm --env-file .env -p 10000:10000 frameguard
```

Then call `http://localhost:10000/scan` with the `X-API-Key` header and multipart `file` field.

## Interpreting the result

- `malware_detected`: VirusTotal reports one or more malicious engine detections.
- `suspicious_detections`: VirusTotal reports one or more suspicious detections and no malicious detections.
- `no_known_threat_detected`: VirusTotal report has zero malicious and suspicious detections and FFprobe parsed the media. This is not a guarantee of safety.
- `malware_analysis_pending`: the file was submitted; the analysis is not complete yet.
- `incomplete_malware_scan`: VirusTotal is disabled, unconfigured, rate-limited, unavailable, or has no report and automatic upload is disabled.
- `invalid_or_unreadable_media`: FFprobe could not parse the file.

`ffmpeg.status=no_decode_errors` means the selected audio/video streams decoded without reported errors. It does not mean the file is benign. ExifTool is a metadata inspector, not an antivirus engine. VirusTotal detections are engine opinions and can include false positives; review the report rather than treating a single number as definitive.

## Security notes and limitations

- This is a **preliminary file-inspection API, not a malware sandbox**. FFmpeg, FFprobe and ExifTool parse attacker-controlled input and may themselves contain vulnerabilities.
- Use a long random API token. Never expose it or the VirusTotal API key in browser-side JavaScript.
- One scan runs at a time per service process. Render Free may sleep after inactivity; the first request after sleep can take time.
- Uploads are written to temporary storage and deleted after processing. Render's filesystem is ephemeral; the service does not archive videos.
- The 100 MiB limit is enforced while copying the upload to a temporary file. The hosting platform may also impose request limits.
- Large, high-resolution, malformed or unusually complex videos may exceed CPU or timeout limits. A timeout means incomplete analysis, not a clean result.
- Do not execute files or extract/run embedded content. For higher-risk samples, use a disposable VM with networking disabled, no shared folders and snapshots.
- Only upload files you are entitled to access and scan. This API does not bypass website access controls, download restrictions, or copyright permissions.
- Render Free is appropriate for personal testing, not a production malware-analysis service.

## Configuration

| Variable | Default | Purpose |
|---|---:|---|
| `API_TOKEN` | required | API authentication secret |
| `MAX_UPLOAD_MB` | `100` | Maximum upload size in MiB |
| `SCAN_TIMEOUT_SECONDS` | `120` | FFmpeg and VirusTotal upload timeout |
| `VIRUSTOTAL_ENABLED` | `false` | Enable VirusTotal lookups/submissions |
| `VIRUSTOTAL_API_KEY` | empty | VirusTotal API key (secret) |
| `VIRUSTOTAL_UPLOAD_UNKNOWN` | `true` | Upload files when their hash has no existing report |
